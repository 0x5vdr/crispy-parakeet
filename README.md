# Trading Journal

A personal trading journal and analytics platform for recording trades, tracking performance, and identifying patterns in trading behavior.

## Overview

Trading Journal is being built to make it easier to review trades beyond simple profit and loss.

The goal is to track metrics such as:

* Win rate
* Average R
* Expectancy
* Profit factor
* Drawdown
* Equity curve
* Performance by setup
* Performance by trading session
* Long vs. short performance
* Rule violations and recurring mistakes

The project is primarily a learning project focused on building a real-world full-stack application from the ground up.

## Goals

The primary goals of this project are to:

1. Build a practical full-stack application.
2. Develop stronger backend and database fundamentals.
3. Learn how to design and structure a production-style codebase.
4. Build useful analytics around trading performance.
5. Eventually experiment with AI-assisted analysis of historical trading data.

## Disclaimer

This application is intended for personal journaling and analytics purposes. It does not provide financial advice or guarantee trading performance.
